PyTorch y CUDA 12.1
Python 3.11.9
Instalar PyTorch con CUDA 12.1
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

Pandas instalar :
pip install pandas scikit-learn matplotlib seaborn xgboost opencv-python rasterio

OpenGL intaslar:

pip install pyopengl pyopengl_accelerate glfw
